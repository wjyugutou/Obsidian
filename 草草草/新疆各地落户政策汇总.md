# 新疆各地落户政策汇总

> 整理日期:2026-08-05。新疆落户政策总体呈"**全面放开 + 精准引才**"双轨特征:普通落户门槛极低(多数地区零门槛),同时各地对高层次/急需紧缺人才给出高额补贴。

---

## 一、自治区层面

### 1. 户籍制度改革(新政发〔2014〕68号)

- 全面放开县级市市区、县人民政府驻地镇和其他建制镇落户限制
- 取消职业限制、大中专毕业生劳动合同限制、投靠婚龄/年限/年龄/婚否限制、投资落户投资额和纳税限制
- 租赁房屋落户:连续居住满 1 年 + 参加社会保险满 1 年
- **南疆实行更宽松落户政策**:不限制落户条件,落户人员享受与当地户籍人口同等教育、社保、计划生育、就业等优惠
- 取消农业/非农业户口区分,统一登记为居民户口;实行居住证制度

### 2. "天池英才"引进计划

- **领军人才专项**:全职引进,能突破关键技术、支撑重点产业、带动新兴学科的高层次人才
- **特聘专家专项**:柔性引进学科带头人、博导、优秀工程师,每年需在疆服务 4 个月以上
- **青年博士专项**:全职引进博士和博士后
- **急需紧缺专业人才专项**:不设具体条件
- 待遇:入选后给予 **20-50 万元一次性生活补助 + 每年 30-100 万元工作经费资助**(一般连续支持 3 年)

### 3. 高校毕业生就业创业补贴

- 创业担保贷款 10 万元以下符合条件的取消反担保;灵活就业社保补贴
- 就业见习补贴(至 2025-12-31)
- 一次性扩岗补助:**每招用 1 人 1500 元**(招用高校毕业生或 16-24 岁登记失业青年,至 2025-12-31)

## 二、各地落户政策

### 乌鲁木齐市(2024年新政,有效期5年)

9 类落户通道,均可携**配偶、子女、父母、配偶的父母**随迁:

| 类别 | 条件 |
|---|---|
| 学历落户 | 中专及以上学历(含职校、国民教育同等学力、留学回国人员) |
| 在校大学生 | 全日制高校在校生;技工院校高级工班、预备技师(技师)班在校生 |
| 专业技术人才 | 国家职业资格目录内专技证书;或获发明专利 |
| 技能人员 | 中级工(四级)及以上技能证书;或各级一、二类职业技能竞赛获奖 |
| 投资创业 | 本市依法注册正常经营企业的法定代表人、股东、高管;个体经营者 |
| 安居落户 | 有房产证;或购买商品住房/公寓/写字楼/商铺已网签并缴契税(含未交付);或房改房集资房;或**居住满1年+缴养老险满6个月** |
| 投靠落户 | 夫妻投靠(持结婚证);父母投靠子女(男60/女55,独生子女父母不限);未婚或残疾子女投靠父母 |
| 退役军人及亲属 | 驻乌部队现役军人亲属;已安置落户的退役军人 |
| 其他 | 公务员、事业编、调动、军转、华侨港澳台、无户籍安置人员等 |

- 办理:线下(派出所/社区警务室)或线上("新疆公安微警务"小程序),5 个工作日批准;"跨省通办""疆内通办"免开准迁证
- 落户地址顺序:住房 → 家庭户口 → 亲属房产 → 单位集体户 → 社区户

### 伊犁州 / 伊宁市(2025年全面放开)

- **居住登记满 6 个月,凭居住证件即可迁入**
- 按投资、从业、学历、技术、就学、投亲、居住等政策均可落户
- 购房落户:凭不动产权证或购房合同+发票,可落本人及配偶、子女、父母
- 引进人才、技术人才、留学归国人员可携配偶、子女、父母迁入
- 州级六类:学历(中专及以上)、人才、投资创业、购房、直系亲属投靠、就业(凭劳动合同)

### 喀什地区(零门槛)

- **不设学历、年龄、就业创业、投靠对象、居住处所性质等限制**,应迁尽迁、应落尽落
- 购房落户(含商品房、经适房、公寓、集资房、房改房、公租房、出租房)、投资创业、学历(中专及以上)等渠道

### 库尔勒市(巴州,2025年全面放开)

8 类条件:人才引进(中专以上学历/初级以上职称,**不受社保、工作年限限制**)、投资创业、购房、就业(劳动合同)、投靠(**不受民族、年龄、婚龄、职业、住所、户别限制**)、租房(不限面积时间)、军人亲属、居住证满 6 个月
- 跨省迁入免回原籍("跨省通办"),线上"新疆公安微警务"

### 其他地州

- 克拉玛依、阿拉尔等地取消学历、社保、房产等限制
- 阿拉尔市(兵团一师):"**组团落户**",四人及以上家庭可获**免费住房及现金补贴** + 创业扶持、教育优惠
- 兵团部分地区职工落户设年龄:男 18-39 周岁、女 18-34 周岁(仅特定区域及职业)

## 四、学历认可度(成人本科 / 无学位证视角)

### 核心结论

- **普通落户**:承认,且学历本就不是门槛。成人高考/自考/函授/电大均属国家承认、学信网可查的国民教育系列学历;乌鲁木齐学历落户表述为"中专及以上学历(含国民教育同等学力)"。但多数地区落户零门槛(居住满6个月/租房/购房/劳动合同即可),**学历不是必要条件,有无学位证无关紧要**
- **人才引进(编制+补贴)**:成人本科基本无门,无学位证是硬伤。绝大多数地州要求**全日制学历 + 学位证书双证**
- **替代路径**:高级职称或高级技师资格可**不受学历限制**(哈密、塔城、自治区指引均明文规定);乌鲁木齐中级工(四级)及以上技能证书即可走"技能落户"

### 各地区人才引进学历要求

| 地州 | 学历要求 | 承认成人本科? |
|---|---|---|
| **塔城** | 仅限公办本科类大学,**明文排除**自考、函授、网教、成教;硕士须"全日制本科起点";要求双证 | ❌ 明确不认 |
| **哈密** | 全日制硕士以上 + 双证;紧缺岗位放宽至全日制本科 | ❌ |
| **昌吉** | C类须"全日制研究生学历、硕士以上学位" | ❌ |
| **克州** | 青年博士(全日制博士双证);骨干第二层次"双一流"全日制本科 | ❌ |
| **喀什** | 青年储备人才须"双一流"学士学位及以上 | ❌ |
| **吐鲁番** | 全日制硕士及以上 | ❌ |
| **阿勒泰** | 高层次:全日制硕士以上或副高以上;急需紧缺:双一流学士 | ❌ |
| **阿克苏** | 原则上全日制硕士以上;紧缺岗位放宽至全日制本科 | ❌ |
| **克拉玛依** | 全日制研究生或双一流全日制本科;或高级职称 | ❌ |
| **和田** | 全日制博士/硕士(三、四类人才) | ❌ |
| **巴州** | 硕士 40 岁以下、博士 45 岁以下 | ❌ |
| **伊犁州** | 硕士及以上(紧缺专业放宽双一流全日制本科) | ❌ |
| **博州** | 双一流高校全日制大学生等 | ❌ |
| **乌鲁木齐**(事业单位引才) | 公告要求"本科及以上学历学位";引才口径为"本科以上学历+职业资格" | ⚠️ 名义未写全日制,但需学位证 |

### 政策依据原文

- 塔城《急需紧缺人才引进实施办法(试行)》(2024):"仅限公办本科类大学,**不含定向培养、委托培养、在职培养、自学考试、函授教育、网络教育、成人教育等**"
- 塔城/哈密历次引才公告报名材料均要求"毕业证书 + **学位证书**"
- 自治区《人才引进政策指引》:"青年博士应具有高校**全日制**博士研究生学历(双证齐全)";"高级技师职业资格……可不受学历条件限制"
- 新疆教育厅(2016):成人高考、自考、电大毕业生"可获得国家承认的电子注册的本、专科毕业文凭"
