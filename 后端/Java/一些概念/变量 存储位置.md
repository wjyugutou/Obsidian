|概念|存储位置|说明|
|:--|:--|:--|
|局部变量（无论基本类型还是引用）|栈|变量本身（8字节引用或4字节int）都在栈帧中|
|对象实例（包括数组、String等）|堆|`new` 出来的东西永远在堆上|
|成员变量 / 静态变量|堆（随对象/类元数据）|不属于栈，即使它是 `int`|
|字面量常量|常量池（方法区/元空间）|`"hello"`, `127` 等编译期确定的值|

```java
public void example() {
    int a = 10;           // 变量a(4字节) + 值10 → 都在栈上 ✅
    int b = 20;           // 变量b(4字节) + 值20 → 都在栈上 ✅

    String s = "hello";   // 变量s(8字节引用) → 栈上
                          // "hello"对象 → 字符串常量池(堆/元空间)

    String t = new String("world"); // 变量t(8字节引用) → 栈上
                                    // new String对象 → 堆上 ✅
                                    // "world"字面量 → 常量池

    MyClass obj = new MyClass(); // 变量obj(8字节引用) → 栈上
                                 // MyClass实例 → 堆上 ✅
                                 // ⚠️ 实例内部的 int field 也在堆上！不在栈上！
}
```

## 方法区

> 方法区 = **存放"类的元数据"的地方**，不是放代码逻辑的，而是放"类长什么样"的描述信息。
> 方法区**确实存储了方法的实际内容**，而不仅仅是"描述信息"。
> 类比理解：如果堆（Heap）是存放运行时对象的"仓库"，那方法区就是存放**蓝图/模具**的"设计图纸室"。

|存储内容|说明|前端类比|
|:--|:--|:--|
|类信息|类名、包名、修饰符、父类、接口列表|TypeScript 的类型声明 / interface 定义|
|字段信息|所有字段的名称、类型、修饰符|class 的属性签名|
|方法信息|方法签名、字节码、异常表、局部变量表|函数的 AST + 编译产物|
|常量池|字面量（字符串/数字）+ 符号引用|类似 webpack 的 module map|
|JIT 编译后的代码|HotSpot 热点代码的本地机器码|Bun/V8 的 TurboFan JIT 缓存|
|静态变量|⚠️ JDK7 及之前在这里；JDK8+ 移到堆中|—|
|Class 对象|⚠️ JDK7 及之前在这里；JDK8+ 移到堆中|—|
