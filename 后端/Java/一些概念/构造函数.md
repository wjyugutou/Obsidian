### 没有 `constructor` 关键字

在 Java 中，**构造器的名字必须和类名完全相同**，且没有返回类型（连 `void` 都不能写）：
```java 
// Java
public class UserService {
    private final Database db;
    
    // 无参构造器 默认有一个 可以不手动写
    public UserService() {
    }

    // ✅ 方法名 = 类名，这就是构造器
    public UserService(Database db) {
        this.db = db;
    }
}
```

|场景|推荐做法|
|:--|:--|
|Spring Service/Controller|只写有参（Lombok `@RequiredArgsConstructor`），让 DI 注入|
|JPA Entity / DTO|永远保留无参 + 按需加有参|
|工具类|`private` 无参 + `throw AssertionError`|
|配置类 / Record|用 `record` 或 Lombok，别手写|
|不确定要不要无参|加上，成本极低，缺了代价极高|
