
## Target (类型)
给什么类型注解

## Retention ()

运行时能否拿到注解，只由 `@Retention(RetentionPolicy.RUNTIME)` 决定，跟 `@Documented` 没有半点关系。

- 注解生效时机
	- 编译时
	- 运行时

## Documented ()

注解的注解, 在生成 **JavaDoc** 时是否保留

## 切面

```java
// 第一步：添加 @Aspect 和 @Component
@Aspect          // 标记为切面类
@Component       // 让 Spring 能扫描到并管理它
public class LogAspect {

    // 第二步：定义“切点”（Pointcut）—— 在哪些地方插逻辑
    @Pointcut("execution(* com.example.service.*.*(..))")
    public void serviceMethod() {}

    // 第三步：定义“通知”（Advice）—— 插入什么逻辑
    @Before("serviceMethod()")  // 在切点方法执行之前执行
    public void beforeLog() {
        System.out.println("方法开始执行：" + System.currentTimeMillis());
    }

    @AfterReturning("serviceMethod()")
    public void afterLog() {
        System.out.println("方法正常结束");
    }

    @Around("serviceMethod()")  // 最强大的，可以完全控制方法执行前后
    public Object aroundLog(ProceedingJoinPoint joinPoint) throws Throwable {
        System.out.println("前置逻辑");
        Object result = joinPoint.proceed(); // 执行目标方法
        System.out.println("后置逻辑");
        return result;
    }
}
```
