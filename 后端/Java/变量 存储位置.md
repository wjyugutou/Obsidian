|概念|存储位置|说明|
|:--|:--|:--|
|局部变量（无论基本类型还是引用）|栈|变量本身（8字节引用或4字节int）都在栈帧中|
|对象实例（包括数组、String等）|堆|`new` 出来的东西永远在堆上|
|成员变量 / 静态变量|堆（随对象/类元数据）|不属于栈，即使它是 `int`|
|字面量常量|常量池（方法区/元空间）|`"hello"`, `127` 等编译期确定的值|

```java
public void example() {
    int a = 10;           // 变量a(4字节) + 值10 → 都在栈上 ✅
    int b = 20;           // 变量b(4字节) + 值20 → 都在栈上 ✅

    String s = "hello";   // 变量s(8字节引用) → 栈上
                          // "hello"对象 → 字符串常量池(堆/元空间)

    String t = new String("world"); // 变量t(8字节引用) → 栈上
                                    // new String对象 → 堆上 ✅
                                    // "world"字面量 → 常量池

    MyClass obj = new MyClass(); // 变量obj(8字节引用) → 栈上
                                 // MyClass实例 → 堆上 ✅
                                 // ⚠️ 实例内部的 int field 也在堆上！不在栈上！
}
```
