## 风险与对策

1. **SB4 资料荒漠**：教程一律看 Spring Boot 3.x 的（90% 兼容），SB4 特有坑查官方文档/源码。搜"Spring Security 过滤器链 原理"这类概念题，别搜"若依 教程"。
2. **拒绝前置补课 → 学夹生**：已确认每个里程碑**内置 30-60 分钟概念学习环节**（已获用户确认）。跳过它就会变成抄代码——从零仿写唯一会失败的姿势。
3. **工具类不仿写**：`StringUtils`、`SpringUtils` 等纯工具直接读源码理解后拿来用，价值在会用不在会写。
4. **范围外模块**：quartz/代码生成器/服务监控不在里程碑内，最后作为"自读源码"习题。

## 每天的执行模板（2-3 小时）

```
1. 概念学习 30min：该步涉及的核心概念(指定资料) → 写 3 行概念笔记
```
