|类类型|推荐做法|对标 NestJS|
|:--|:--|:--|
|`@Service` / `@Controller`|`@RequiredArgsConstructor`，不加无参|Provider 构造器注入|
|JPA `@Entity`|无参(`protected`) + 业务有参|TypeORM Entity|
|Request/Response DTO|`@Data` 或 `record`，保留无参|class-validator DTO|
|配置属性 `@ConfigurationProperties`|`record` 或 Lombok `@Value`|ConfigModule|
|纯工具类|`private` 无参 + throw|导出函数模块|
|Domain Model / Value Object|只有有参，不加无参|领域实体|
