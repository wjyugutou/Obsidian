token 是<font color="#ff0000">一块文字</font>, 根据各个模型的 分词器 切分, 从海量文字切出来的 最短常用片段
大模型 的对话窗口 能装的 <font color="#ff0000">块</font> 是有限的, token 用来节约块的使用

## 分词器

### 词表

有很多词块, 每块都有自己的编码

#### 词表的生成
BPE(BYTE pair encoding) 是一套方法/算法
1. 训练
	1. 通过训练生成 词表/规则表(切分规则)
2. 切分

### 切分规则

### 工作流程

1. 规范化
2. 预切分: 按照 中文/英文/标点符号... 粗略切分成一些 <font color="#ff0000">块</font>
3. 分词模型 把<font color="#ff0000">块</font> 按照 <font color="#ff0000">词表</font>和<font color="#ff0000">规则</font> 详细切分
4. 变编号 去词表 转成对应编号, 编号发给LLM, LLM回答编码 再解码输出给用户
