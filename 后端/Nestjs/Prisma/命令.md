| 命令            | 方向            | 改数据库？ | 改 Schema？ | 改 Client 代码？ | 典型时机             |
| :------------ | :------------ | :---- | :-------- | :----------- | :--------------- |
| `migrate dev` | Schema → DB   | ✅ 是   | ❌ 否       | ✅ 自动         | 开发时改了 model      |
| `db pull`     | DB → Schema   | ❌ 否   | ✅ 是(覆盖)   | ❌ 需手动        | 对接已有库/DBA改表      |
| `generate`    | Schema → Code | ❌ 否   | ❌ 否       | ✅ 是          | 改完 schema / CI构建 |
