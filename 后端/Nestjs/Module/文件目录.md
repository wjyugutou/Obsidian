## 一个完整 NestJS 11 + Zod 4 模块：

```
src
└── modules
    └── users
        ├── users.module.ts
        ├── users.controller.ts
        ├── users.service.ts
        │
        ├── schemas
		│   ├── user.internal.schema.ts // 内部使用
	    │   ├── user.response.schema.ts // 脱敏 返回给前端
	    │   ├── create-user.schema.ts 
	    │   └── update-user.schema.ts
        │
        ├── dto
        │   ├── create-user.dto.ts
        │   └── update-user.dto.ts
        │
        ├── repositories
        │   └── user.repository.ts
        │
        └── types
            └── user.type.ts
```
