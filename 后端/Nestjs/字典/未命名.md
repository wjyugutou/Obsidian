```
【启动】
  onModuleInit
    ├─ Redis 有数据？→ loadFromRedis() → 填充 local Map ✅
    └─ Redis 没数据？→ reloadFromDB() → 写 Redis + 填充 local Map ✅
    └─ 启动 Pub/Sub 订阅

【请求进来】
  拦截器 → dictService.translateObject() → 读 local Map（同步）✅

【后台改字典】
  updateDictData()
    → reloadFromDB()
      → DB 查全量
      → 写 Redis Hash
      → 刷新本机 local Map
      → publish('dict:reload')
        → 其他实例收到 → loadFromRedis() → 刷新各自 local Map

【兜底】
  每 5 分钟 → loadFromRedis() → 防止 Pub/Sub 丢消息
```
