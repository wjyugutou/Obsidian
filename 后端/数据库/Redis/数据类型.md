# Redis 数据结构与 Java 对应关系及使用场景

> Redis 本身只有一种存储模型：**key → value**，key 和 value 都是字符串。所谓"类型"指的是 value 的存储结构。所有 key 均可用任意类型，按场景选型即可。

## 核心概念

- Redis 命令是**原子**的（单线程执行模型），可用于分布式锁、计数器、防重
- 所有 value 本质都是字符串，`Map<String, String>` 是 Hash 而非 String
- 注意区分：**键级别映射**（任意类型都是一个 key 对应一个 value）和 **值内部结构**

## 五大数据结构

| Redis 类型 | 对应 Java 结构 | 内部实现（近似） | 典型使用场景 |
|---|---|---|---|
| **String** | `String` | 简单动态字符串 SDS | 缓存对象 JSON、计数器、分布式锁、验证码、限流 |
| **Hash** | `Map<String, String>` | 哈希表 / 压缩列表 | 存储对象字段（用户信息、购物车）、可单独更新某个字段 |
| **List** | `List<String>` | 双向链表 / 压缩列表 | 消息队列（LPUSH+BRPOP）、最新消息、时间线、评论列表 |
| **Set** | `Set<String>` | 哈希表 / 整数集合 | 去重、关注/粉丝集合、标签、抽奖（SRANDMEMBER） |
| **ZSet** | `TreeMap<Double, String>`（按分数排序） | 跳表 + 哈希表 | 排行榜、延迟队列（score=时间戳）、限流滑动窗口 |

## 扩展数据结构

| Redis 类型 | 对应 Java 结构 | 使用场景 |
|---|---|---|
| **Bitmap**（基于 String） | `BitSet` | 用户签到、活跃用户统计、布隆过滤器的位操作 |
| **HyperLogLog** | 概率算法（无直接对应） | UV 统计（精确度 0.81% 误差，占用极低内存） |
| **Geo**（基于 ZSet） | 地理坐标结构（如自封装类） | 附近的人、门店距离计算 |
| **Stream** | 消息流（对应 `List` 的增强版） | 可靠消息队列（消费者组、ACK 机制） |
| **Pub/Sub** | 观察者模式 / `MessageListener` | 广播通知（不持久化，不建议做业务消息队列） |

## 命令速查

| 操作 | String | Hash | List | Set | ZSet |
|---|---|---|---|---|---|
| 添加 | `SET k v` | `HSET k f v` | `LPUSH/RPUSH k v` | `SADD k v` | `ZADD k score member` |
| 读取 | `GET k` | `HGET k f` | `LRANGE k 0 -1` | `SMEMBERS k` | `ZRANGE k 0 -1` |
| 删除 | `DEL k` | `HDEL k f` | `LREM k 1 v` | `SREM k v` | `ZREM k member` |
| 存在 | `EXISTS k` | `HEXISTS k f` | — | `SISMEMBER k v` | `ZSCORE k member` |
| 数量 | `STRLEN k` | `HLEN k` | `LLEN k` | `SCARD k` | `ZCARD k` |

## Java 使用示例（Spring Data Redis）

```java
// String：缓存
stringRedisTemplate.opsForValue().set("user:" + id, jsonStr, 30, TimeUnit.MINUTES);

// Hash：对象字段存储
opsForHash().put("user:" + id, "name", "zhangsan");
opsForHash().put("user:" + id, "age", "20");

// List：消息队列（生产者）
opsForList().leftPush("queue:order", orderId);
// 消费者阻塞读取
String orderId = opsForList().rightPop("queue:order", 10, TimeUnit.SECONDS);

// Set：去重/标签
opsForSet().add("user:tags", "java", "redis");

// ZSet：排行榜
opsForZSet().add("rank:game", userId, score);
Set<String> top10 = opsForZSet().reverseRange("rank:game", 0, 9);
```

## 选型决策

1. 单个值 / 计数器 / 锁 → **String**
2. 对象多字段、需单独更新字段 → **Hash**（比整个 JSON 序列化更省流量）
3. 先进先出队列 / 栈 → **List**
4. 去重判断 / 集合运算 → **Set**
5. 需要排序 / 按分数取范围 → **ZSet**
6. 大流量 UV 统计 → **HyperLogLog**
7. 可靠消息队列（需消费确认）→ **Stream**
