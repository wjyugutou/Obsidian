### `let ref x` 与 `let &x`
- **`let ref x = v;`** —— 让 `x` 变成 `&v`（**创建**一个引用，`v` 本身还在原地）
- **`let &x = r;`** —— 要求 `r` 是引用，并把 `x` 绑成 `*r`（**解引用**，把里面的值取出来）

```rust
let s = String::from("hi");

// ref：borrow 出来一个 &String，s 仍然有效
let ref r = s;
println!("{}", s);   // ✅ s 没被 move

// &：要求右边是引用，取出里面的 String —— 但 String 不是 Copy
let &t = &s;         // ❌ cannot move out of borrowed content  
```

|写法|右边需要是|变量绑定成|原值是否被 move|
|---|---|---|---|
|`let ref x = v;`|任意值 `T`|`&T`（一个引用）|❌ 不 move|
|`let &x = r;`|必须是 `&T`|`T`（解引用后的值）|Copy 类型：不 move ; 非 Copy：**编译错误**|
